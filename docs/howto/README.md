# How-To Guides

Step-by-step guides for common Impulse tasks.

| Guide | What it covers |
|-------|---------------|
| [Certificates](/docs/howto/certificates) | Configure Impulse listener identities and apply certificate reloads |
| [Configuration](/docs/howto/configuration) | Building a complete config file — listeners, upstreams, routing, load balancing, health checks, host policy, forwarded headers, performance tuning |
| [Running Impulse](/docs/howto/run) | Running Impulse — directly, as a systemd service, in Docker; startup sequence, health checks, graceful shutdown, troubleshooting |

## Quick path for first-time setup

1. **Configure certificate files** → [Certificates](/docs/howto/certificates)
2. **Write your config** → [Configuration](/docs/howto/configuration) (or copy `config/config.reverse.yaml`)
3. **Start Impulse** → [Running Impulse](/docs/howto/run)
