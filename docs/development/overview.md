# Development Overview

This section is for contributors and maintainers working on the codebase itself.

## Start Here

- [Contributing Guide](https://github.com/impulse-proxy/impulse/blob/master/CONTRIBUTING.md) covers workflow expectations and project contribution basics.
- [Architecture Overview](/docs/architecture/overview) explains runtime
  structure, current crates, and ownership boundaries before you modify them.
- [Codebase Map](/docs/development/codebase-map) is the quickest route to finding the correct crate or module for a change.
- [Testing Strategy](/docs/development/testing-strategy) explains what the current suite is protecting.
- [Invariants](/docs/development/invariants) records the behavioral rules contributors should preserve.
- [Adding Features Safely](/docs/development/adding-features) gives the expected workflow for non-trivial changes.
- [Benchmarking](/docs/development/benchmarking) describes local Criterion microbenchmarks.
- [Roadmap](/docs/roadmap) captures the larger direction and missing capability areas.
- [Changelog](/docs/changelog) shows recently landed work and the project’s release narrative.
